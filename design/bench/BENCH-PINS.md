# Bench parts: pins, pivots and moving layers

All coordinates are in each part's own viewBox. Use `BENCH.PINS[key][pin]` in JS, or `BENCH.place(key, x, y, scale)` to drop a part into a scene `<svg>` and get its pins back in scene units (`.pin('a')`).
Every part is generated by `bench-gen.py`, which writes `*.svg` and `bench-art.js`. Edit the generator and re-run `python3 bench-gen.py`; never edit the outputs by hand.
SVG strings use single quotes only. The shared `<defs>` (ids `bn-*`) are embedded in each standalone .svg. In the app, call `BENCH.installDefs()` once and inline the parts from `BENCH_ART`.

Pivots use `transform-origin` in viewBox px on the moving `<g>`, with the default SVG `transform-box: view-box`. A part nested inside a scene `<svg>` keeps its own viewBox, so the pivots stay correct.

## The binding screw (inside every part)

`g.bn-screw[data-pin=NAME]` contains, bottom to top:

- `.washer`
- `.wire-end`: empty until `BENCH.tighten()` draws the bare copper loop between the washer and the head
- `.head`: a circle, with cx/cy/r giving the screw centre
- `.slot`: rotates about the screw centre; `.tight` = `rotate(270deg)`
- `.pin-ring`: amber when `.on`

`data-pin` matches the pin names in the table above. Use `querySelector(".bn-screw[data-pin='b']")` to reach a terminal.

## Cloth wire

`BENCH.wire(x1,y1,x2,y2,{sag,ctrl,color,net,cls})` returns `g.cw.COLOR[data-w=NET]` with these layers:

- `.cw-out`: dark edge
- `.cw-base`: cloth colour
- `.cw-b1` / `.cw-b2`: braid, as two offset dash patterns
- `.cw-sheen`
- `.cw-sig`: the amber logic overlay, shown when `.on`
- `.cw-flow`: moving dashes, shown when `.on.flow`
- `.cw-tip` × 2: bare copper ends

Colours: `brown` (default), `red`, `green`, `black`, `cream`.

Sag: the control point sits below the midpoint by `sag × length × 2`, scaled down for steep runs. `ctrl:[x,y]` overrides it to route round a part.

States: `.on` = 1 (amber), none = 0 (plain cloth), `.x` / `.unknown` = not computed (desaturated, dotted). `BENCH.setWire(g, 1|0|null)`.
